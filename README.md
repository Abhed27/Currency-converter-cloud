# 🌍 Cloud Currency Converter

A dynamic **Currency Converter Web Application** built using **Node.js**, **HTML**, **CSS**, and **JavaScript**, designed with a modern interactive UI and cloud-ready architecture.

---

## 🚀 Project Overview

This project allows users to convert currencies in real-time using live exchange rates.
It includes a stylish interface, dynamic flags, parallax background effects, and a conversion history panel.

The goal of this project is to demonstrate:

* 🌐 Full Stack Web Development
* ☁️ Cloud-ready Architecture
* ⚡ API Integration
* 🎨 Modern UI/UX Design

---

## ✨ Features

✔ Real-time currency conversion
✔ Dynamic country flags
✔ Conversion history table
✔ Parallax world map background
✔ Welcome start screen
✔ Smooth animations and transitions
✔ Node.js backend API integration
✔ Responsive and interactive UI

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

git clone https://github.com/Abhed27/Currency-converter-cloud.git
cd Currency-converter-cloud

---

### 2️⃣ Start Server

npm install
npm start

Server runs on:
http://localhost:3000
